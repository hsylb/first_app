- # Project structure

- `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` stay at the project root. GitHub Pages serves the root `index.html`.
- `00_planning/` is for planning notes and sketches.
- `02_validation/` is for hand calculations and test cases.
- `03_output/` is for screenshots and exported results.

Save each new file in the folder that matches its purpose. Keep the four named project files at the root; do not add unrelated files there.

After each request, add an entry to `prompts.md` describing what was asked, what changed, and whether it worked.
